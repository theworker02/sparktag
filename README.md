# sparktag

Spark URLs and tag query parts with stable normalization.

**Site:** https://theworker02.github.io/sparktag/

## Install / run

```bash
git clone https://github.com/theworker02/sparktag.git
cd sparktag
node src/cli.js
node --test
```
